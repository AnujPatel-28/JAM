# Changelog

All notable changes to JAM are documented here.

This project follows [Semantic Versioning](https://semver.org/) and the format from [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- Open-source contribution, security, release, and community guidelines.
- Continuous integration and automated tagged-release workflows.
- Accessible modal dialogs with focus trapping, Escape-to-close, and focus restoration.
- Keyboard support for the host seek bar and two-step queue dismiss confirmation.
- ARIA labels, landmarks, and heading structure across lobby, room, and modals.

### Changed

- Higher-contrast muted text, solid accent, and gradient tokens.
- Focus rings, type scale, reduced-motion coverage, and button/input polish across the UI.
- Clearer verification-code and music-start copy.

## [0.1.0] - 2026-09-09

### Added

- Synchronized YouTube playback with clock and drift correction.
- Ephemeral public and password-protected rooms.
- Collaborative queue, voting, chat, and host controls.
- Database migrations, realtime authorization, Turnstile support, and security hardening.
